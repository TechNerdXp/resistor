# Challenge Blocker Extension

This Chrome extension blocks access to addictive websites like YouTube, Facebook, Reddit, Twitter, and Instagram by presenting a challenge before allowing access.

## Features
- Blocks multiple addictive sites
- Three difficulty levels for challenges
- Customizable blocked sites list
- Simple UI for settings

## Installation
1. Load the extension in Chrome as unpacked from this folder.
2. Visit a blocked site to see the challenge.

## Usage
- Set difficulty in options.
- Add/remove sites in settings (requires extension reload for site changes).

## Challenges
- Easy: Type "resist"
- Medium: Solve a math problem
- Hard: Type a full sentence

Note: Site list changes require reloading the extension.
